# CRUD Operations using JSP

This is a simple project I created **while learning CRUD operations using JSP, Servlets, JDBC, and MySQL**.

The main purpose of creating this project was to understand how basic **Create, Read, Update, and Delete (CRUD)** operations are performed in a Java web application.

While working on it, I practiced creating JSP pages, sending data through forms, handling requests using Servlets, connecting the application with MySQL using JDBC, and performing database operations.

### ✨ What I Practiced

* Creating and displaying data
* Adding new records to the database
* Reading and displaying records
* Updating existing records
* Deleting records
* Connecting Java with MySQL using JDBC
* Sending data between JSP and Servlets
* Handling form submissions
* Writing and executing SQL queries

### 🛠️ Technologies Used

* **Java**
* **JSP**
* **Servlets**
* **JDBC**
* **MySQL**
* **HTML & CSS**

This project was created **only for learning and practice**. It helped me understand the basic flow of a Java web application and how the **JSP → Servlet → JDBC → MySQL** flow works.

I built this project step by step while learning the concepts, so this repository also represents my practice and learning process.

**Learn → Practice → Understand → Build**
